# Пример перевода Markdown в PDF

Проект преобразует файлы Markdown в документы PDF с определёнными требованиями к форматированию.

статья Советов П.Н., Горчаков А.В. «Модели и алгоритмы автоматической генерации учебных задач по работе с системой git и разрешению зависимостей между пакетами».

## Использовано

1. pandoc
2. pandoc-crossref
3. MiKTeX

## Запуск

```
make runpandoc
```

Результат: `result_article.pdf`.
