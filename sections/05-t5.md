# Модель T5

Модель ruT5 в отличие от ruBERT реализует полную архитектуру трансформера, включающую как кодировщик, так и авторегрессивный декодировщик, и следует парадигме приведения всех задач к единому формату «текст-на-текст», что превращает её в универсальный инструмент, где задача извлечения информации формулируется как задача генерации целевого текста по заданному шаблону.

Декодировщик ruT5, в основе которого лежит механизм причинного внимания (causal attention), гарантирует, что при генерации каждого следующего токена учитываются только предыдущие, что обеспечивает корректность авторегрессивного процесса, что позволяет ruT5 не только извлекать информацию в структурированном виде, но и переформулировать её, создавая новые связные тексты на основе извлеченных данных [@shavrina2021].

Листинг 2. Применение ruT5.

``` {.python}
from transformers import T5Tokenizer, T5ForConditionalGeneration

model_name = "sberbank-ai/ruT5-base"
tokenizer = T5Tokenizer.from_pretrained(model_name)
model = T5ForConditionalGeneration.from_pretrained(model_name)

# Пример: извлечение ключевых аспектов (аспект-ориентированное извлечение)
input_text = ("отзыв: Камера у этого смартфона превосходная, особенно ночью. "
"Однако батарея разряжается очень быстро. Дизайн современный.")
prompt = "извлеки основные аспекты и их тональность: " + input_text

input_ids = tokenizer(prompt, return_tensors="pt", max_length=256, truncation=True).input_ids
output_ids = model.generate(input_ids, max_length=50, num_beams=4)
output_text = tokenizer.decode(output_ids[0], skip_special_tokens=True)

print(f"Извлеченные аспекты: {output_text}")
# вывод: "камера: положительный; батарея: отрицательный; дизайн: положительный"
```
