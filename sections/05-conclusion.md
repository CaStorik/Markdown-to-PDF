**Заключение**

В статье рассмотрены алгоритмы автоматической генерации учебных задач из области программной инженерии. Предложены 2 новых генератора задач, таких как генератор задач на работу с СКВ git и генератор задач на разрешение зависимостей. В задаче на работу с СКВ git учащимся предлагается создать новый репозиторий git из командной строки, граф коммитов которого бы совпадал со сгенерированным графом коммитов, приведённым в постановке задачи. Проверка решений задач такого типа осуществляется преподавателем вручную. В задаче на разрешение зависимостей учащимся предлагается выбрать версии устанавливаемых пакетов по сгенерированному графу зависимостей пакетов из постановки задачи. На этапе генерации графа зависимостей гарантируется, что соответствующая ему SAT-задача имеет единственное решение. Проверка решений задач такого типа выполняется автоматически системой управления обучением. Результаты работы внедрены в учебный процесс РТУ МИРЭА и используются в дисциплине «Конфигурационное управление».

Дальнейшие исследования могут быть направлены на разработку новых генераторов индивидуальных NP-полных задач из области программной инженерии и по программированию [@andrianova2022], причём важным этапом при оценке качества новых генераторов является проверка того, какой процент сгенерированных задач может быть решён при помощи LLM. Разработка устойчивых к LLM генераторов позволит не только защититься от заимствования студентами чужих решений, но и предотвратить нежелательное применение LLM студентами для сдачи зачётов или экзаменов без участия или с минимальным участием обучающегося.
