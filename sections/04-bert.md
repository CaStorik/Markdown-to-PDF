# Модель BERT

Модель ruBERT, являющаяся локализацией BERT для русского языка, представляет собой стек идентичных слоёв-трансформеров, использующих только компонент кодировщика. Ключевое преимущество модели -- глубокое двунаправленное контекстуализированное представление слов, достигаемое за счёт предобучения на задачах Masked Language Modeling (MLM) и Next Sentence Prediction (NSP).

В рамках MLM модель обучается предсказывать случайно маскированные токены, используя контекст как слева, так и справа, что формирует у неё способность к тонкому семантическому анализу. Данная особенность делает ruBERT исключительно эффективным инструментом для задач извлечения информации, где требуется не просто наличие слова, а его роль в конкретном контексте [@devlin2019].

Например, для извлечения именованных сущностей модель должна не только идентифицировать слово «Пушкин» как существительное, но и, проанализировав окружение, классифицировать его как «PER» (личность) в предложении «Пушкин написал „Евгения Онегина“», и как «LOC» (местоположение) в предложении «Он живет на улице Пушкина».

Способность ruBERT генерировать контекстно-зависимые эмбеддинги для каждого токена подходит для токен-уровневых задач классификации, таких как NER.

::: listingbox
Листинг 1. Загрузка и применение ruBERT.

``` {.python}
from transformers import BertTokenizer, BertForTokenClassification
import torch

# Загрузка модели, предобученной для NER
tokenizer = BertTokenizer.from_pretrained('DeepPavlov/rubert-base-cased-ner')
model = BertForTokenClassification.from_pretrained('DeepPavlov/rubert-base-cased-ner')

text = "Пушкин написал «Евгения Онегина» в Болдине, а памятник Пушкину стоит на площади."
inputs = tokenizer(text, return_tensors="pt", truncation=True)
outputs = model(**inputs)
predictions = torch.argmax(outputs.logits, dim=2)

# Сопоставление предсказанных ID с тегами сущностей (B-PER, I-PER, B-LOC и т.д.)
tags = model.config.id2label
predicted_tags = [tags[p.item()] for p in predictions[0][1:-1]] # Игнорируем [CLS] и [SEP]

# Показываем результат с исходными токенами
tokens = tokenizer.tokenize(text)
print(list(zip(tokens, predicted_tags)))
# вывод: [('Пушкин', 'B-PER'), ('написал', 'O'), ('«', 'O'), ('Евгения', 'B-PER'), ('Онегина', 'I-PER'),
# ('»', 'O'), ('в', 'O'), ('Болдине', 'B-LOC'), (',', 'O'), ('а', 'O'), ('памятник', 'O'),
# ('Пушкину', 'B-PER'), ('стоит', 'O'), ('на', 'O'), ('площади', 'B-LOC'), ('.', 'O')]
```
:::

Однако архитектурное решение ruBERT, ориентированное на кодирование и классификацию, накладывает ограничения на его применимость к задачам порождения связного текста. Авторегрессивная генерация, при которой каждое следующее слово предсказывается на основе предыдущих, в чистом BERT-подобном кодировщике реализована неэффективно, так как его внимание изначально заточено на анализ уже существующего полного контекста, а не на его последовательное построение.
