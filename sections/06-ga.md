# Генетический алгоритм для оптимизации гиперпараметров

Процесс дообучения моделей требует тонкой настройки гиперпараметров, которые существенно влияют на итоговое качество модели. В качестве ключевых гиперпараметров рассматриваются:

- скорость обучения (learning rate, $lr$);
- коэффициент снижения весов (weight decay, $wd$);
- размер батча (batch size, $bs$);
- доля warmup-шагов (warmup ratio, $\alpha$).

Традиционные методы оптимизации, например такой как поиск по сетке (grid search), становится неэффективными из-за высокой вычислительной стоимости каждой оценки конфигурации, что критично для больших моделей [@so2019].

Для решения этой задачи применяется генетический алгоритм (ГА) -- эволюционный метод, имитирующий естественный отбор. ГА оперирует популяцией возможных решений, каждая из которых представляет собой вектор гиперпараметров $\theta$.

В данной работе задача оптимизации гиперпараметров формализуется как поиск вектора:

$$
\theta = (lr,bs,wd,\alpha) \in \Theta,
$$ {#eq:theta}

минимизирующего функцию потерь $\mathcal{L}$ на валидной выборке $D_{\mathrm{val}}$:

$$
\theta^{*} = \arg\min_{\theta} \mathcal{L}\left(M(\theta),\ D_{\mathrm{val}}\right),
$$ {#eq:opt}

где $M(\theta)$ -- модель, дообученная с гиперпараметрами $\theta$.

Вычислительная реализация оптимизационного процесса организована с использованием библиотек PyTorch и Transformers. Для каждой особи в популяции генетического алгоритма выполняется цикл оценки, включающий следующие этапы:

1. Преобразование векторного представления особи $X$ в рабочие гиперпараметры модели:

$$
\eta = 10^{X[0]},\quad B = 2^{X[1]},\quad \lambda = X[2],\quad \omega = X[3],
$$ {#eq:decode}

где $\eta$ -- скорость обучения, $B$ -- размер мини-батча, $\lambda$ -- коэффициент L2-регуляризации, $\omega$ -- доля warmup-этапов.

2. Загрузка предобученной модели с последующим добавлением классификационного слоя для задачи NER (7 классов: O, B-PER, I-PER, B-LOC, I-LOC, B-ORG, I-ORG).

3. Цикл оптимизации с использованием алгоритма AdamW с заданными $\eta$ и $\lambda$, линейным расписанием изменения скорости обучения с warmup-фазой протяженностью $\omega \cdot T$ шагов, где $T$ -- общее количество шагов обучения. Градиенты нормируются с коэффициентом 1.0.

4. Оценка качества обученной модели на валидационной выборке с вычислением усредненной F1-меры. Для исключения влияния служебных токенов применяется маскирование меток со значением $-100$.

Функция приспособленности возвращает отрицательное значение F1-меры:

$$
F(x) = -F1(M_{X},\ D_{\mathrm{val}}),
$$ {#eq:fitness}

что соответствует задаче минимизации в рамках генетического алгоритма.

::: listingbox
Листинг 3. Реализация генетического алгоритма для оптимизации гиперпараметров.

``` {.python}
from geneticalgorithm import geneticalgorithm as ga

# Пространство поиска гиперпараметров
varbound = np.array([
[-6, -3], # learning_rate: 10^-6 ... 10^-3
[1, 4], # batch_size: 2^1=2 ... 2^4=16
[0.0, 0.1], # weight_decay: 0.0 ... 0.1
[0.0, 0.3] # warmup_ratio: 0.0 ... 0.3
])

# Типы переменных
vartype = np.array(['real', 'int', 'real', 'real'])

# Функция оценки
def evaluate_hyperparams(X):
    lr = 10 ** X[0] # learning rate
    bs = int(2 ** X[1]) # batch size
    wd = X[2] # weight decay
    warmup = X[3] # warmup ratio
    # Обучение и оценка модели
    f1 = train_and_evaluate_model(lr, bs, wd, warmup)
    return -f1 # Минимизируем отрицательную F1-меру

# Запуск оптимизации
optimizer = ga(function=evaluate_hyperparams,
dimension=4,
variable_type_mixed=vartype,
variable_boundaries=varbound)
optimizer.run()
```
